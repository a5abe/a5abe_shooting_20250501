# 🚀 Rust WebAssembly Shooting Game

A simple 2D shooting game built with Rust and WebAssembly.

## 🛠️ Prerequisites

- [Rust](https://www.rust-lang.org/tools/install) (1.70.0+)
- [wasm-pack](https://rustwasm.github.io/wasm-pack/installer/)
- A web server for local testing

## 🏗️ Building the Project

1. Clone the repository
2. Run the build script:
   ```bash
   chmod +x build.sh
   ./build.sh
   ```
3. The script will:
   - Check if wasm-pack is installed
   - Build the WebAssembly module

## 🎮 Running the Game

After building, you can open `index.html` in a browser. Due to CORS restrictions in modern browsers, you may need to use a local web server:

```bash
# Using Python 3's built-in server
python -m http.server

# Or if you have Node.js installed
npx serve
```

Then open your browser to http://localhost:8000 (or whichever port your server uses).

## 🎯 Game Controls

- Arrow keys or WASD to move
- SPACE to shoot
- ESC to pause the game

## 🧩 Project Structure

- `src/` - Rust source code
  - `lib.rs` - Main entry point
  - `game.rs` - Core game logic
  - `entity.rs` - Game entities (player, enemies, bullets)
  - `rendering.rs` - Canvas rendering
  - `input.rs` - Keyboard input handling
- `pkg/` - Compiled WebAssembly output (generated by build)
- `index.html` - Game HTML page
- `build.sh` - Build script
